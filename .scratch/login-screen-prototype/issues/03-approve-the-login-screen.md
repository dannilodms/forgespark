# 03 - Approve the login screen

Status: ready-for-human
Blocked by: 02

Read `../spec.md` first.

## What to do

This is the maintainer's decision; an agent cannot make it.

Open the login route of the prototype and go through it as a person would:

- the Start step and the Code step, with the keyboard alone and with the mouse;
- every scenario of the two groups in the prototype bar;
- each of the three languages, reading every text;
- light and dark;
- a desktop window and a 375px-wide one.

For anything to change, write what and why under `## Comments`. Each change becomes a new issue in this folder, and this issue waits for it.

## Outcome

Write the approval under an `## Answer` heading, with the date. From then on the screen can be rebuilt in `apps/web`: the texts in the three languages are copied across, and the notes for the rebuild in `../spec.md` go to the issue that builds it.
